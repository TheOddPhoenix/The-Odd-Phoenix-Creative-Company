# Approved project content

Add approved entries in src/data/projects.js. Until approved projects exist, the portfolio page is noindex and excluded from the sitemap.

Each entry should include: slug, title, category (Writing, Graphic Design, Photography, Video, Digital Content, Communications), image, imageAlt, description, objective, services (array), deliverables (array), and optional results. Include results only when supported by evidence. Record publication permission and source attribution internally. Build project routes/cards when adding the first approved entry; do not publish this template as a project.
